# Suggestions issues des phrases du profil

Dans l'écran de communication, « Suggestions de ma mémoire » propose trois
réglages : désactivées, mots ou phrases. Le choix est conservé pour ce profil
dans ce navigateur ; les textes proposés ne sont pas enregistrés dans ce réglage.

1. Composez un message avec vos touches, puis terminez-le.
2. Activez **Mots** pour retrouver tous les mots des phrases acceptées du profil,
   ou **Phrases** pour choisir une de ces phrases. La recherche et les pages
   permettent de parcourir la mémoire entière, sans filtre sur le début du message.
3. En mode mots, ajoutez les mots dans l'ordre souhaité, puis choisissez
   « Proposer cette phrase de mots ». Les répétitions sont possibles ; vous
   pouvez annuler le dernier mot ou effacer cette proposition.
4. Dans « Vérifier ce que je veux dire », confirmez, corrigez ou rejetez la
   proposition. Elle devient un nouveau souvenir uniquement après acceptation.

Les mots proviennent exclusivement du texte actuellement accepté : une correction
humaine remplace le texte initial. Les mots de liaison sont inclus. Par exemple,
« Je veux boire de l’eau. » fournit « Je », « veux », « boire », « de », « l’ »
et « eau ». Un dessin est affiché seulement lorsqu'une touche validée du même
profil porte exactement ce mot et possède une représentation validée cohérente.
Un mot sans correspondance reste utilisable en texte. Aucun dessin n'est inventé.

Ces deux modes n'appellent aucun provider IA. Aucun mot extérieur, phrase d'un
autre profil ou proposition non acceptée n'alimente les suggestions. Un profil
vide affiche un état explicite : désactivez ce mode pour créer puis accepter
une première formulation avec le parcours habituel. Aucun basculement IA
automatique n'a lieu.

« Écarter » masque une suggestion pour ce message. Cela ne supprime pas sa phrase
d'origine ; « Réafficher les suggestions écartées » annule ce masquage. Rejeter
une nouvelle proposition ne rejette pas les souvenirs qui ont servi à la composer.

Le serveur vérifie les sources à la proposition et avant sa première acceptation.
Une phrase retirée ou corrigée entre-temps exige une actualisation et un nouveau
choix. Une réponse perdue peut être réessayée sans créer un doublon. La sauvegarde
du profil conserve les références des propositions et les remappe à la restauration.
Les touches et leurs positions ne sont jamais modifiées par ce parcours.
